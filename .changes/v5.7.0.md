## v5.7.0 - 2026-11-25
### Added
* `tilde deploy` deploys a project whose agents use its own ontology's tools and signals in one run when the environment does not exist yet: its dry-run `Apply` names the environments it creates (`ApplyRequest.new_ontology_environments`), and the CLI checks the tools and routine signals on their connections (`tilde_ontology/<project>-<environment>`) against the compiled ontology, refusing an undeclared signal with the object and the signals it declares.
* `@trytilde/iac`: `tildeOntology.environment(project, environment)` is an ontology environment's own connection, and a routine's `signal.type` takes `@trytilde/ontology`'s `SignalRef`, whose data keys the routine's filters.
* Connection setup prefill on provider pages (the same contract as Tilde Cloud): a setup URL may carry `name=<account name>` and `field.<key>=<value>`, which the brokering page forwards to the provider page. `useSetup` fills the account name while the connection still has the provider's placeholder name, and `CredentialForm` fills schema fields, skipping write-only fields, secret-looking keys and values outside a field's choices; saved drafts win and everything stays editable. `@trytilde/connection-ui` exports `readPrefill`, `withPrefill` and `secretKey` for provider-owned pages.
