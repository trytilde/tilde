## v5.1.0 - 2026-11-18
### Added
* `tilde sandbox connect` wires a sandbox for gateway egress: it keeps the egress token its registration issues, adds the egress environment to every shell, writes git URL rewrites to `/etc/gitconfig`, and `tilde sandbox credential` answers git for the gateway with the egress token. Older gateways send none of this and nothing changes.
