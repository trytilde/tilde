## v3.1.2 - 2026-11-12
### Added
* Routines: an agent's Routines tab creates prompts that run the agent on a five-field UTC cron schedule or when a connection emits a signal, each firing in a new thread whose title and prompt are templates over the signal's variables. Connections gain a `signal` capability, ported from the trytilde/api signal providers: GitHub App, Slack, AgentMail, Linq, WhatsApp (Meta and Telnyx), Sentry and Firecrawl connections emit signals.
* Sandboxes: blueprints launch E2B or Modal VMs for agents, with sandbox tools, reuse modes, encrypted environment variables and blueprint tools callable from inside the VM through `tilde sandbox`.
* Add memory banks: agents recall, write, supersede and forget facts through built-in memory tools (sidecar-hosted agents included, answered by the gateway) in banks of their own or shared ones (read or read-write, optionally kept per person), with hybrid full-text and pgvector recall over embeddings from an inference connection, and MemoryService for people to curate banks, memories and embedding settings. Deleting an agent deletes its own bank. Postgres now needs the pgvector extension, 0.8 or later.
* Add the Memory pages: a sidebar entry listing memory banks, each bank's path tree, searchable and filterable memories with their history, sources and replacements, people's facts, settings and linked agents, and administrators' embedding settings. An agent's Capabilities gain a Memory section that gives a new agent a bank of its own and shared banks, and changes them afterwards.
* Add wikis: trees of Markdown reference pages that agents read and edit through built-in wiki tools (search, grep, read, list, write, delete), with every change kept as a revision and concurrent edits refused rather than overwritten. A Wikis sidebar page lists them with each wiki's page tree, editor, history and search, and an agent's Capabilities can give it a wiki of its own and shared wikis.
* Memory banks can synthesize memories from linked agents' conversations and linked wikis through their own chat model, with evidence for each memory and people's facts left untouched.
### Changed



* Connection setup forms: `Form` from `@trytilde/connection-ui` validates only the fields it renders and shows every validation failure in the page instead of relying on browser bubbles, which sandboxed setup frames can hide. The GitHub App and Slack app pages register only the current step's fields, so Continue on "Create an app" no longer does nothing, and the GitHub organization pattern is valid under the `v` regex flag.
