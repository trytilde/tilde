## v5.4.1 - 2026-11-23
### Added
* `tilde deploy --check` builds a project's ontologies as a deploy would (evaluates each, has Tilde compile it, bundles its handler module and builds its spaces against the returned contract) and stops: nothing is uploaded or changed, and the working tree may be dirty. It needs only the npm packages and Tilde's compile RPC, so a project's CI can check its ontology without any server-side binary.
### Changed

* Modal blueprint sandboxes pick up a moved image tag. The launcher resolves the blueprint image's tag to its digest at the registry and builds `FROM <image>@sha256:…`, so Modal's image cache, which keys on the `FROM` line, builds again when `:latest` moves instead of running whatever it built first. If the registry can't be reached, it builds from the tag and logs a warning. E2B blueprints launch a template's latest build already.
