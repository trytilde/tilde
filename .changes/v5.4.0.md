## v5.4.0 - 2026-11-23
### Changed

* `tilde deploy --dry-run` shows each ontology slot binding that changes as `slot: current → new`, and counts the unchanged ones.
* `tilde deploy` builds a project's ontologies on the client and uploads artifacts: each ontology's IR, evaluated with the project's own `@trytilde/ontology` (install it beside each ontology, and `@trytilde/spaces` in its spaces) and checked by Tilde Cloud (`CompileOntology`, whose errors fail the deploy before anything changes), its handler module and its spaces, built against the contract Tilde compiles. It needs Node 22 or newer and a Tilde Cloud with client builds; Tilde Cloud no longer builds sources.
### Removed
* `ChatService.InvokeTool`, `SandboxService.InvokeTool` and `SidecarService.Relay`, which SDKs, CLIs and sidecars of 5.2 and later no longer call (`InvokeToolStream` and `RelayStream` replace them); `tilde sandbox call` no longer falls back to `InvokeTool`.
