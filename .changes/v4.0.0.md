## v4.0.0 - 2026-11-16
### Added
* `@trytilde/embed` and `@trytilde/embed-server`: embed Tilde Cloud dashboards (themed, auto-sized, with navigation and action events), agent chats and connection setup for your application's own users, behind one server handler holding an embed key; a Next.js adapter. `@trytilde/chat-proxy` also accepts an embed key that names the agent.
### Changed

* Tilde is now licensed under AGPL-3.0-only. The client SDKs (TypeScript and Python), `proto/` and `tilde-contracts` stay Apache-2.0; the CLI follows the gateway (AGPL-3.0-only). Releases before this one remain available under Apache-2.0.
* `@trytilde/chat-ui` now has the Dispatch (openbot) chat look: grouped grey and black bubbles, day separators, a header with the agent avatar, a find bar, a floating pill composer and queue, hover Reply and Copy, and session rows with agent avatars, unread dots and a ⌘K search, in light and dark. The `--tc-*` CSS variables are replaced by Dispatch's palette variables.
