## v5.2.0 - 2026-11-20
### Added
* Sandbox images to try Tilde sandboxes with: `ghcr.io/trytilde/sandbox-debian-node`, `sandbox-debian-python` and `sandbox-debian-full` (both, plus Docker Engine and Docker Compose). Each is Debian with the `tilde` CLI of the same release and common agent tools (git, gh, jq, ripgrep, fd, build tools), and is tagged with the release version.
### Changed

* The TypeScript and Python SDKs call tools over `ChatService/InvokeToolStream`, which streams heartbeats while the tool runs, so tool calls longer than a proxy's idle timeout (such as 60 s behind a load balancer) no longer fail.
* Long calls survive proxies with idle timeouts (an AWS load balancer cuts a connection silent for 60 s). `ChatService.InvokeToolStream` and `SandboxService.InvokeToolStream` stream a heartbeat every 10 s while a tool runs, then the result (`tilde sandbox call` uses it, falling back to `InvokeTool`); sidecars relay over `SidecarService.RelayStream`, bounded by 45 s of silence instead of 15 s in all; `WatchThread` sends a keepalive frame (no activity, same cursor); a non-streamed inference call silent for 20 s is answered 200 with JSON whitespace until the provider's body. Management RPCs waiting on outside work fail after 45 s with their own error, or finish skill source syncs in the background. `InvokeTool` and `Relay` remain for older SDKs and sidecars.
